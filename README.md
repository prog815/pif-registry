## Что кодирует реестр ПИФ

**Реестр паевых инвестиционных фондов** — официальный перечень фондов, зарегистрированных Банком России. Он отвечает на вопросы **«Существует ли такой фонд?»**, **«Действует ли он сейчас?»** и **«Кто им управляет?»**.

В текущем снимке справочника содержится более **8 000 записей**. Реестр представлен плоским списком, который включает в себя:

- **Тип фонда** (Открытый, Закрытый, Биржевой, Интервальный).
- **Статус** (Действует, Исключён из реестра, Приостановлен, Зарегистрирован).
- **Категорию** (Фондов, Акций, Облигаций, Смешанных инвестиций и др.).
- **Реквизиты** (Номер правил доверительного управления, даты регистрации и окончания формирования).
- **Участников** (Спецдепозитарий, регистратор).

> **Важно про другие финансовые организации.** Этот реестр содержит только паевые инвестиционные фонды. Если вам нужно проверить банк, страховую компанию или микрофинансовую организацию, используйте соответствующие разделы на сайте Банка России.

## Для кого и зачем

Справочник предназначен для инвесторов, аналитиков, юристов и специалистов по комплаенсу.

Он пригодится, если вам нужно:
- проверить, действует ли фонд, в который вы планируете инвестировать;
- найти номер правил доверительного управления для сверки документов;
- узнать, какой спецдепозитарий обслуживает конкретный фонд;
- посмотреть историю фонда (когда исключён и по какой причине);
- отфильтровать фонды по типу (например, только биржевые) или статусу.

## Возможности интерфейса

- **Мгновенный поиск.** Результаты появляются по мере ввода — без кнопки «Найти».
- **Поиск по реквизитам.** Введите название фонда, номер правил, ИНН/ОГРН спецдепозитария или категорию.
- **Два фильтра.** Выпадающие списки по **Типу фонда** и **Статусу** позволяют мгновенно сузить выборку.
- **Копирование в один клик.** Клик по номеру правил копирует его в буфер обмена. Внизу экрана появится подтверждение.
- **Поделиться карточкой.** Кнопка `📤 Поделиться` формирует полный текст с реквизитами фонда, ссылкой на карточку и всеми статусами, после чего открывает системное меню или модалку.
- **Прямые ссылки на карточки.** Каждый фонд можно передать через `?code=…` в адресе.
- **Подсветка совпадений.** Искомые слова и цифры выделяются прямо в карточке.

## Примеры запросов

- `Золото` — найдёт все фонды, в названии которых есть это слово.
- `0001-44504664` — откроет карточку конкретного фонда по номеру правил.
- `Паллада` — найдёт фонды под управлением этой УК.
- `Биржевой` (в фильтре «Тип») — оставит только биржевые ПИФы.

**Популярные категории:**
- `Акций` — фонды, инвестирующие в акции;
- `Облигаций` — фонды облигаций;
- `Фондов` — фонды фондов.
